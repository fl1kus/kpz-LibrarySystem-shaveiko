# kpz-LibrarySystem-shaveiko

## Опис
LibrarySystem-shaveiko - це веб-застосунок для автоматизації обліку книг у бібліотеці та керування процесом їх бронювання. Система дозволяє користувачам швидко знаходити потрібні видання в каталозі та переглядати їх актуальний статус у реальному часі.
## Технології
- Мова програмування: Python 3.12
- Фреймворк: FastAPI
- База даних: PostgreSQL
